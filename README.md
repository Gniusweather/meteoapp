# meteoapp (RWCAPP)

Live METAR, TAF, SYNOP encoder, ATC map, and weather tools for Curaçao, Aruba, and Bonaire.

**Live:** https://gniusweather.github.io/meteoapp/

## Files

- `index.html` — main app (upload latest from Grok when features change)
- `sw.js` — service worker v14 (network-first HTML, small precache)
- `manifest.webmanifest` — PWA
- `icon.svg` — app icon

## Pages

Settings → Pages → Deploy from branch `main` / `/ (root)`.
